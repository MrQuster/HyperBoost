# Device Profile Detector Review Guide

## 1. Назначение
Проверка корректности распознавания прошивки устройства, аппаратных возможностей, региона ROM и выбор стратегии фолбэков.

## 2. Проверяемые сценарии
1. **Чтение системных свойств**:
   - Чтение через рефлексию `android.os.SystemProperties.get(key)`.
   - Запасной путь через чтение вывода `getprop` при SecurityException или ограничениях рефлексии.
2. **Регион ROM**:
   - При отсутствии региональных меток выставлять статус «Неизвестно» / "Unknown", а не дефолтный "CN".
3. **Видимость пакетов (<queries>)**:
   - Проверка наличия в `AndroidManifest.xml` пакетов `com.miui.securitycenter`, `miui.systemui.plugin`, `com.samsung.android.sm` и др.
4. **Ручной выбор профиля (Manual Override)**:
   - Принудительное переопределение профиля пользователем не должно ложно заявлять о наличии аппаратных фич (например, Xiaomi Super Island на физическом Google Pixel).
5. **Форматирование версий API**:
   - Корректная обработка полного формата `SDK_INT_FULL` (например, 3700002 -> "37.2").

## 3. Чек-лист
- [ ] Все юнит-тесты в `DeviceProfileDetectorTest.kt` выполняются без ошибок.
- [ ] Кэширование профиля сбрасывается при обновлении прошивки (проверка смены `Build.FINGERPRINT`).
