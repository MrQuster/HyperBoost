# Liquid Glass UI Review Guide

## 1. Назначение
Проверка UI компонентов, плавности 60/90/120 FPS, корректности тапов по нижней панели, адаптивности к масштабу шрифта и тем оформления.

## 2. Архитектурные требования к UI
1. **Нижняя панель с линзой (GlassLensTabBar)**:
   - Единый источник истины: `selectedIndex` управляется родительским состоянием навигации.
   - Тап по любой из 5 вкладок обязан гарантированно переключать экран.
   - Клиппинг: линза не должна вылезать за пределы скругления панели (`clip(shape)`).
   - Учёт системных отступов: `WindowInsets.navigationBars`.
2. **Анимация волны внутри круга (HomeScreen)**:
   - Обрезка по форме круга (`clip(CircleShape)`) до применения размытия или шейдера.
   - Чтение анимированных параметров строго в фазе рисования (`Modifier.graphicsLayer` или `Modifier.drawWithCache`), исключая избыточные рекомпозиции всей страницы на каждый кадр.
3. **Читаемость и доступность**:
   - Контраст текста и иконок на полупрозрачном стекле $\ge 4.5:1$.
   - Корректное отображение при масштабе шрифта до 130% без обрезания подписей (`TextOverflow.Ellipsis`, авто-перенос).
   - Поддержка 5 вкладок: Главная, Эквалайзер, Устройства, Настройки, Система.

## 3. Чек-лист
- [ ] Контент экрана прокручивается и не перекрывается нижней панелью (правильный `contentPadding`).
- [ ] В режиме энергосбережения или на старых GPU сложные AGSL шейдеры упрощаются до RenderEffect blur или полупрозрачной подложки.
- [ ] Все отступы и радиусы скругления берутся из `LocalGlassTokens.current`.
