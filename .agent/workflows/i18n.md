# Workflow: /i18n

## Шаги выполнения:
1. Выполнить поиск невынесенной кириллицы в исходниках Kotlin:
   ```bash
   grep -rnP '[А-Яа-яЁё]' app/src/main/java
   ```
2. Запустить юнит-тест синхронизации ресурсов:
   ```bash
   ./gradlew testDebugUnitTest --tests "*.DspAndLocalizationTest.English and Russian strings_xml have 100 percent identical key sets*"
   ```
3. Проверить `locales_config.xml` и манифест на поддержку мультиязычности.

## Условие остановки:
Наличие расхождений в ключах `strings.xml` или присутствие кириллических строк в коде интерфейса.

## Формат итога:
- Список найденных захардкоженных строк с файлами и строками
- Статус совпадения ключей `values` и `values-ru`
