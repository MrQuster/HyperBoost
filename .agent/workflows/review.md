# Workflow: /review

## Шаги выполнения:
1. Получить текущий diff в рабочей ветке:
   ```bash
   git diff
   ```
2. Провести аудит изменений по чек-листу скилла `code-review`:
   - Отсутствие утечек `Context` и `AudioEffect`
   - Корректность жизненного цикла Foreground Service
   - Безопасность многопоточности и отсутствие блокировок
   - Наличие флагов `FLAG_IMMUTABLE`
   - Отсутствие захардкоженных строк
3. Проверить запуск тестов:
   ```bash
   ./gradlew testDebugUnitTest
   ```

## Условие остановки:
Обнаружение регрессии или нарушение правил проекта.

## Формат итога:
Вердикт: APPROVED / REQUEST_CHANGES с перечнем замечаний по строкам.
