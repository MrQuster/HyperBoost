# Workflow: /build

## Шаги выполнения:
1. Запустить очистку и полную сборку:
   ```bash
   ./gradlew clean test lint assembleDebug
   ```
2. Проверить код завершения команды.
3. Проанализировать вывод на наличие предупреждений Kotlin и ошибок Lint.
4. Зафиксировать размер сгенерированного APK:
   ```bash
   ls -lh app/build/outputs/apk/debug/app-debug.apk
   ```

## Условие остановки:
Если любая задача Gradle завершается с ошибкой (code != 0), немедленно остановить процесс и вывести подробный стек ошибки.

## Формат итога:
- Статус сборки: УСПЕХ / ОШИБКА
- Время выполнения
- Количество тестов: успешно / провалено
- Список предупреждений компилятора
- Размер Debug APK
