# HyperBoost Agent Rules

## 1. Зафиксированные решения (НЕЛЬЗЯ МЕНЯТЬ)
- Остров, уведомление, плитка, виджет и ярлыки: кнопки строго «−10%» и «+10%», компактный переключатель вкл/выкл.
- Лимит усиления: нет верхнего предела усиления (шкала до 1000% и до 10000% в unlimited mode). Внутри приложения ЗАПРЕЩЕНЫ предупреждения о громкости или вреде для слуха.
- Навигация: ровно пять вкладок: Главная, Эквалайзер, Устройства, Настройки, Система.
- Локализация: полная поддержка RU и EN строго через ресурсы `res/values/strings.xml` и `res/values-ru/strings.xml`. Запрещены захардкоженные строковые литералы в UI и сообщениях сервиса.
- Брендинг: иконка-капля; автор MrQuster; applicationId `io.github.mrquster.hyperboost`.
- Сборка: публикация через GitHub Releases с подписанными APK; R8/minification включён в release.

## 2. Безопасность и Git
- Все изменения выполняются в ветке `chore/agent-audit`. Не коммитить в main/master.
- ЗАПРЕЩЕНЫ push, создание тегов и релизов без прямого разрешения пользователя.
- НИКОГДА не читать, не выводить в лог/чат и не коммитить секреты: `*.jks`, `keystore.properties`, `local.properties`, токены, пароли.
- ЗАПРЕЩЕНЫ деструктивные команды (`git reset --hard`, `git clean -fd`, `rm -rf`) без подтверждения.

## 3. Требования к коду и архитектуре
- Стек: Kotlin, Jetpack Compose, MVVM, StateFlow, DataStore.
- Дизайн-система: использование токенов `LocalGlassTokens.current` вместо «магических чисел».
- Главный поток: запрещены любые блокирующие вызовы (диск, IPC, рефлексия, замеры) на Main Looper.
- Аудио-поток (PCM DSP / AudioRecord): строгий запрет на аллокации памяти (GC pressure), блокировки (synchronized/mutex) и логирование внутри цикла сэмплов.
- Android IPC: все `PendingIntent` обязаны содержать `FLAG_IMMUTABLE` (или `FLAG_MUTABLE` только если система объективно требует мутабельности для inline reply).

## 4. Верификация
- Перед любым сообщением об успешном исправлении или завершении задачи ОБЯЗАТЕЛЬНО запустить `./gradlew test lint assembleDebug`.
- Проверять отсутствие кириллицы в kotlin-файлах (`grep -rnP '[А-Яа-яЁё]' app/src/main/java`) и соответствие ключей `values/strings.xml` и `values-ru/strings.xml`.
- Никаких выдуманных фактов: если поведение или API не проверено физически, помечать «нужно проверить».
