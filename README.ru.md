HyperBoost — приложение с открытым исходным кодом для Android (Android 10+, API 29+), которое поднимает громкость звука выше стандартных 100% на встроенных динамиках, Bluetooth-наушниках, колонках и USB-ЦАП. Интерфейс выполнен на полупрозрачных панелях Liquid Glass с размытием фона и разделен на 5 вкладок. Поддерживается отображение в Суперострове Xiaomi (`miui.focus.param`) и Live Updates в Android 16+.

## Как устроено усиление звука

В разных версиях Android и оболочках вендоров аудиоэффекты работают по-разному. В HyperBoost встроены два независимых звуковых тракта:

1. **Мягкий режим (Session 0):** Подключает аппаратный `LoudnessEnhancer` и 6-полосный каскад `DynamicsProcessing` к общему микшеру системы (`sessionId = 0`). Работает без задержки звука и действует во всех приложениях, включая потоковые сервисы с DRM-защитой.
2. **Захват звука (PCM DSP):** Перехватывает стереопоток 48 кГц через `MediaProjection` и `AudioPlaybackCapture`. Обработка идёт через 64-битный цифровой умножитель, Biquad low-shelf фильтр баса (95 Гц), расширитель стереосцены Mid/Side и непрерывный soft-knee лимитер (`tanh`). Позволяет обойти системные ограничения на прошивках, где сессия 0 заглушается вендорным микшером.

## Совместимость с устройствами

Приложение разработано исключительно для Android. При запуске модуль `DeviceProfileDetector` проверяет параметры системы и выбирает подходящую схему работы:

| Устройство / Оболочка | Статус проверки | Особенности работы |
| :--- | :--- | :--- |
| **Xiaomi 17T Pro (HyperOS 4, Android 17 / API 37)** | Проверено на реальном устройстве | Полная поддержка: оба аудиодвижка, управление в Суперострове (`miui.focus.param`) кнопками `−10%` / `+10%`, переходы в настройки автозапуска и батареи. |
| **Другие Xiaomi / Redmi / POCO (HyperOS 1–3, MIUI 14)** | Должно работать (требуется проверка) | Используется тот же формат фокусных уведомлений и системных интентов Xiaomi. |
| **Устройства с Android 16+ (Pixel, Nothing, Motorola)** | Должно работать (требуется проверка) | Системные Live Updates и стандартные настройки энергосбережения AOSP. |
| **Samsung One UI, OnePlus, OPPO, realme, vivo, Honor** | Должно работать (требуется проверка) | Стандартное медиа-уведомление с кнопками `−10%` / `+10%` и пошаговые инструкции настройки фона. Если встроенный Dolby Atmos ограничивает сессию 0, переключитесь на «Захват звука». |

Если вы запустили приложение на своём смартфоне, откройте вкладку **«Система»**, нажмите **«Скопировать отчёт»** и прикрепите его к [Issue](https://github.com/MrQuster/HyperBoost/issues) — это поможет актуализировать таблицу.

## Возможности

- **Шкала без искусственного потолка:** Стандартный диапазон от 0% до 1000% (с отметками 100%, 200%, 500%), а в настройках можно включить расширенный режим до 10 000% для тихих записей.
- **Быстрый шаг −10% и +10%:** В Суперострове Xiaomi, уведомлении, виджете и плитке быстрых настроек доступны кнопки `−10%`, `+10%` и `Вкл/Выкл`.
- **Рабочие ползунки баса, объёма и баланса:** Приложение проверяет наличие аппаратных `BassBoost` и `Virtualizer`. Если они не поддерживаются прошивкой, эффекты автоматически переводятся на 6-полосный каскад `DynamicsProcessing.PreEq` или программный Biquad/Mid-Side DSP.
- **Раздельные профили:** Уровень усиления запоминается отдельно для динамика, каждого Bluetooth-устройства, проводных наушников и USB-ЦАП.
- **Полная изоляция от сети:** В манифесте приложения нет разрешения `android.permission.INTERNET`.

## Ограничения

- **Ограничения захвата звука (DRM):** Приложения с флагом `ALLOW_CAPTURE_BY_NONE` (голосовые вызовы, банковские клиенты, защищённое видео) блокируют перехват потока. Для них используйте **«Мягкий режим (Session 0)»**.
- **Белый список Суперострова в HyperOS:** На некоторых глобальных прошивках системный плагин `miui.systemui.plugin` разрешает отображение кастомного острова только системным пакетам. В этом случае приложение автоматически переключается на постоянное уведомление со ступенями `−10%` и `+10%`.

## Установка из Releases

1. Скачайте файл `HyperBoost-vX.Y.Z.apk` из раздела [Releases](https://github.com/MrQuster/HyperBoost/releases/latest).
2. Откройте файл на телефоне и подтвердите установку. Если Google Play Protect покажет предупреждение о неизвестном разработчике, выберите **«Подробнее»** &rarr; **«Всё равно установить»**.
3. На устройствах Xiaomi / HyperOS:
   - В приложении откройте **«Настройки»** &rarr; **«Настройки уведомлений»** и включите **«Фокусные уведомления / Суперостров»**.
   - В мастере фона выставьте контроль активности в положение **«Нет ограничений»** и разрешите **Автозапуск**.

Проверка контрольной суммы перед установкой:
```bash
sha256sum -c HyperBoost-v1.4.0.apk.sha256
```

## Сборка из исходников

Для сборки требуются JDK 17 и Android SDK (API 35):

```bash
# Клонирование репозитория
git clone https://github.com/MrQuster/HyperBoost.git
cd HyperBoost

# Запуск тестов и сборка отладочного APK
./gradlew clean test lintDebug assembleDebug

# Сборка релизного APK с R8 (результат в app/build/outputs/apk/release/)
./gradlew assembleRelease -PversionName="1.4.0"
```

## Частые вопросы (FAQ)

**Почему нет усиления в некоторых приложениях?**  
Некоторые плееры и звонки запрещают запись звука политикой безопасности. На главном экране переключитесь на **«Мягкий режим (Сессия 0)»**.

**Как включить Суперостров на Xiaomi?**  
Откройте **Настройки** телефона &rarr; **Уведомления и строка состояния** &rarr; включите **Фокусные уведомления** для HyperBoost. Во вкладке **«Система»** в приложении нажмите «Самотест острова» для проверки.

**Как отключить абсолютную громкость Bluetooth?**  
Если Bluetooth-наушники выходят на максимум слишком рано, откройте **«Для разработчиков»** в настройках Android и включите тумблер **«Отключить абсолютную громкость»**.

## Важная информация

Длительное прослушивание на предельной громкости может привести к перегрузке динамиков смартфона и утомлению слуха. Выбирайте комфортный уровень усиления и включайте мягкий лимитер (`tanh`) в настройках звука при появлении искажений.
