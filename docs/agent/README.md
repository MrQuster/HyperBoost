# Инфраструктура агентов HyperBoost

В проекте настроена полноценная система автономной работы ИИ-агентов, командной разработки и контроля качества в соответствии с экосистемой Google Antigravity.

## 1. Структура директорий
```text
.
├── AGENTS.md                          # Главные правила проекта (всегда активны)
├── .agent/ (и синхронизированный .agents/)
│   ├── rules/
│   │   └── 00-core-rules.md           # Обязательные ограничения и инварианты
│   ├── skills/                        # Модульные скиллы (SKILL.md)
│   │   ├── android-build-test/        # Сборка, тесты, lint, разбор ошибок
│   │   ├── adb-debug/                 # Отладка через ADB, logcat, dumpsys
│   │   ├── audio-effects-check/       # Тракт звука, формулы dB/mB, лимитер
│   │   ├── glass-ui-review/           # Ревью Liquid Glass UI и навигации
│   │   ├── island-debug/              # Xiaomi Super Island и Live Updates
│   │   ├── i18n-check/                # Проверка локализации RU/EN
│   │   ├── device-detect-review/      # Аудит детектора прошивки и ROM
│   │   ├── perf-measure/              # Замеры FPS, памяти, старта, размера APK
│   │   ├── release-github/            # Подготовка к публикации на GitHub
│   │   └── code-review/               # Чек-лист независимого ревью
│   └── workflows/                     # Сценарии слэш-команд
│       ├── build.md                   # /build
│       ├── install-log.md             # /install-log
│       ├── audit.md                   # /audit
│       ├── review.md                  # /review
│       ├── measure.md                 # /measure
│       ├── i18n.md                    # /i18n
│       └── release-check.md           # /release-check
└── docs/agent/
    ├── PROJECT_MAP.md                 # Карта проекта и точек входа
    ├── ROLES.md                       # Роли и оркестрация суб-агентов
    └── README.md                      # Данный документ
```

## 2. Использование воркфлоу (слэш-команд)
В интерфейсе чата или при вызове сценариев доступны команды:
- `/build` — запускает очистку, unit-тесты, lint и assembleDebug, возвращая краткую сводку.
- `/install-log` — устанавливает собранный debug APK на физическое устройство через adb и снимает логи.
- `/audit` — проводит сквозной аудит по всем скиллам.
- `/review` — выполняет независимое ревью текущего git diff.
- `/measure` — производит замеры холодного старта, памяти и кадров.
- `/i18n` — валидирует отсутствие захардкоженных строк и совпадение ключей перевода.
- `/release-check` — проверяет готовность release сборки с R8.

## 3. Роли суб-агентов
Роли зарегистрированы в системе Antigravity (`audio-engineer`, `independent-reviewer`, и др.). Каждая роль выполняет задачи в своей зоне ответственности. Все изменения обязательно верифицируются независимым ревьюером перед коммитом в ветку `chore/agent-audit`.

## 4. Как расширять инфраструктуру
1. **Добавление нового скилла**: создать папку `.agent/skills/<название>/` с файлом `SKILL.md`, содержащим YAML frontmatter (`name`, `description`).
2. **Добавление нового правила**: создать `.agent/rules/<название>.md` с краткими проверяемыми требованиями.
3. **Добавление нового воркфлоу**: создать `.agent/workflows/<команда>.md` с разделами «Шаги выполнения», «Условие остановки» и «Формат итога».
